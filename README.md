TechFlow

Sistema de Gerenciamento de Ordens de Serviço

O TechFlow é um sistema desenvolvido para facilitar o gerenciamento de ordens de serviço, clientes, técnicos e equipamentos.

Objetivo

Desenvolver uma aplicação que permita cadastrar, consultar e gerenciar ordens de serviço, acompanhar seus status e organizar as informações dos clientes e técnicos.

Tecnologias

HTML

CSS

JavaScript

Node.js

Express

MySQL

Git e GitHub

Funcionalidades previstas

Cadastro e consulta de clientes.

Cadastro e consulta de técnicos.

Criação e gerenciamento de ordens de serviço.

Consulta dos detalhes das ordens de serviço.

Gerenciamento do status das ordens de serviço.

Dashboard inicial.
